Task Tracker

Setup required

Follow these steps once to get your free permanent task tracker running. Takes about 5 minutes.

1
Create a free JSONBin account

Go to jsonbin.io → Sign up free → Go to API Keys → copy your Access Key.

2
Create a bin

In JSONBin, click + Create Bin → paste in {"tasks":[],"nextId":1} → save. Copy the Bin ID from the URL. Then click the bin's Settings (gear icon) → set Read Access to Public. This lets volunteers load tasks without needing credentials.

3
Enter your credentials

✓ Admin credentials saved!

Host on GitHub Pages (free)

Go to github.com → New repo → upload this HTML file as index.html → Settings → Pages → Deploy from main branch.
